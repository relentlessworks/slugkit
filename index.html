slugkit

Agentic-first URL slug generation service. Generate URL-safe slugs from text with unicode transliteration, configurable separators, and validation.

Go CGO_ENABLED=0 Single Binary No Database MCP

Quick Start

make build
./slugkit

# Generate a slug
curl "http://localhost:8472/slug?text=Hello+World"
# → hello-world

# Unicode transliteration
curl "http://localhost:8472/slug?text=Café+Münster"
# → cafe-munster

# Validate a slug
curl "http://localhost:8472/validate?slug=hello-world"
# → slug=hello-world valid=true
